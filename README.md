**Zerodha Clone**

A full-stack Zerodha (Kite) inspired trading platform built using the MERN stack.
This project replicates the core structure and functionality of a modern online trading dashboard and is intended for learning and portfolio use.

Overview
This application is divided into three major modules:

Frontend
Backend
Dashboard

Each module is designed to mirror real-world production architecture, including authentication, protected routes, and deployment configuration.

Features
JWT-based user authentication
Secure and protected routes
Dashboard with portfolio summary
Holdings and positions management
Orders tracking
Funds section
Watchlist functionality
Persistent navigation layout
Deployed frontend and backend

Tech Stack

Frontend
React
React Router
Context API
Vite
Backend
Node.js
Express.js
MongoDB
Mongoose
JSON Web Tokens (JWT)
